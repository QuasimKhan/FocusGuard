Visual Onboarding

Easy 4-Step First-Time Setup

Follow these four visual cards once after installing so Android lets FocusGuard protect you reliably.

Step 01 · Download

Install the Signed APK

Tap Download Direct APK above (or install via Indus Appstore / APKPure), open the file, and allow Install unknown apps if prompted.

Fastest Method: Direct APK installs in 5 seconds with zero store sign-in required.
Step 02 · Core Engine

Enable Accessibility

Tap Open Accessibility settings in FocusGuard → select FocusGuard and switch it ON.

Android 13–16 Greyed Out? Open Settings → Apps → FocusGuard → tap ⋮ (top right) → Allow restricted settings first.
Step 03 · 24/7 Reliability

Set Battery to Unrestricted

Long-press FocusGuard → App info → Battery → Unrestricted. On Xiaomi, POCO, Realme, Vivo, or Oppo, also enable Autostart.

Prevents aggressive phone battery savers from pausing your shield overnight.
Step 04 · Web & Study OS

Activate Local DNS Shield

Open the Web tab → toggle Block Adult Contents ON and tap OK on Android's local VPN dialog.

Chrome Tip: Turn Off Chrome → Settings → Privacy & security → Use secure DNS.
