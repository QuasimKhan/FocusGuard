3-Minute Android Setup

Because FocusGuard uses system-level Accessibility and local VPN APIs, follow these steps after installing the APK.

1

Install FocusGuard

Download the signed APK above (or install via Indus Appstore / APKPure) and approve Install unknown apps when prompted.

2

Enable the Accessibility Engine (Android 13–16)

Open FocusGuard → tap Open Accessibility settings → select FocusGuard and turn it ON.

Restricted Setting? Open Phone Settings → Apps → FocusGuard → tap the 3-dot menu (⋮) → Allow restricted settings, then return to Accessibility.
3

Exempt from Battery Optimization

Long-press the FocusGuard icon → App info → Battery → Unrestricted. On Xiaomi, POCO, Realme, Vivo, or Oppo, also enable Autostart.

4

Activate Web Shield & Study OS

Switch Local DNS Adult & Web Shield ON in the Web tab (turn off Use secure DNS in Chrome settings for system-wide filtering).
