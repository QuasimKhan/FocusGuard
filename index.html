Quick Onboarding

3-Minute Android Setup

Because FocusGuard uses system-level Accessibility and local VPN APIs, complete these steps once after installing.

1

Install FocusGuard

Download the signed APK above (or install via Indus Appstore / APKPure) and allow Install unknown apps when prompted.

2

Enable the Accessibility Engine (Android 13–16)

Open FocusGuard → tap Open Accessibility settings → select FocusGuard and switch it ON.

Restricted Setting? Open Phone Settings → Apps → FocusGuard → tap the 3-dot menu (⋮) → Allow restricted settings, then return to Accessibility and toggle FocusGuard ON.
3

Prevent OEM Battery Killing

Long-press the FocusGuard icon → App info → Battery → Unrestricted / No restrictions. On Xiaomi, POCO, Redmi, Realme, Vivo, or Oppo, also enable Autostart.

4

Activate Web Shield & Study OS

Switch Block Adult Contents (Local DNS Shield) ON in the Web tab (turn off Use secure DNS in Chrome settings for full browser filtering).
