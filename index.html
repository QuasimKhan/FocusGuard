3-Minute Onboarding

First-Time Setup Guide

Step 01

Install Signed APK

Download above and allow Install unknown apps when prompted.

Step 02

Enable Accessibility

Switch FocusGuard ON. On Android 13–16, tap App Info → ⋮ → Allow restricted settings first.

Step 03

Unrestricted Battery

Set Battery → Unrestricted (and Autostart on Xiaomi, POCO, Realme, Vivo, Oppo).

Step 04

Activate Web Shield

Toggle Block Adult Contents ON in the Web tab (disable Chrome Secure DNS for full filtering).
